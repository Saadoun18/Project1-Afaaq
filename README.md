# Simple Project — Portfolio Demo

This tiny project contains a minimal landing page and a simple portfolio hero section.

Files:

- `index.html` — Main landing page.
- `styles.css` — Shared stylesheet.
- `HeroSection.html` — Portfolio page with photo cards (uses placeholder images).

To view locally, open `index.html` in your browser. Click "View Portfolio" to open the hero section.

Replace the placeholder photos in `HeroSection.html` with your own image files or URLs.
